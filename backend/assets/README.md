# Stand-in assets

`portrait-standin.jpg` is the public-domain photograph of Grace Hopper held in the
Matplotlib sample-data collection (original: U.S. Navy). It is used only as a
base image for deterministic photo-rule fixtures and for an all-match demo
upload. It is not a student record and no identity inference is made from it.

All mark sheets under `backend/synthetic/` are generated, fictional documents.
